# Project conventions

- Never use the em dash character ("—") in any copy, UI text, or chat replies. Use a comma, colon, or full stop instead.
- App name: **Alba**, by Swissquote.
- Palette: black on white, one accent (#FA5B35, tint #FEDCD3 / rgba(250,91,53,…))`). Positive performance in soft green #1E8A5E (tint #E3F3EA). No red for losses; negatives stay neutral grey.
- Single deliverable: `Alba Prototype.dc.html`.
- Type: Swissquote CT (uploads/, weights 400/500/700) for all text, including micro-labels.
- Audience: designed for women (~90% of users) but not exclusive.
